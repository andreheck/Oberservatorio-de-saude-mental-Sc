# Oberservatorio-de-saude-mental-Sc
O Observatório é uma aplicação web para transparência, monitoramento de políticas públicas e participação social em saúde mental. O recorte de dados e equipamentos atualmente implementado é Itajaí (SC). O portal não deve ser apresentado como órgão público formalmente instituído nem como representante oficial do COMUSA sem autorização expressa.
